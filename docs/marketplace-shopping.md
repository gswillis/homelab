# Marketplace shopping guide

Target: a used small-form-factor desktop to run Proxmox. Budget about $150 to $350 for the unit, ideally with RAM and an SSD included. Prices vary by region, so compare several listings.

## Search terms

- "HP EliteDesk 800 G4 SFF", "HP EliteDesk 800 G5 SFF"
- "HP ProDesk 400 G5 SFF", "HP ProDesk 400 G6 SFF"
- "Dell OptiPlex 7060 SFF", "Dell OptiPlex 7070 SFF", "Dell OptiPlex 7080 SFF"
- "Lenovo ThinkCentre M720s", "Lenovo ThinkCentre M920s"
- Generic: "small form factor desktop i5 8th gen", "SFF PC 16GB 256GB"

## Which size

- **SFF (small form factor):** usually has room for a 3.5" hard drive, which you need for the 4 TB photo drive. Best fit for this plan.
- **Tiny, Mini or Micro (EliteDesk Mini, OptiPlex Micro, ThinkCentre Tiny):** quieter and smaller, but usually no 3.5" bay. They would need an external drive, which is less ideal for the photo library.

## Check in each listing

- [ ] CPU is Intel 8th generation or newer, i5 or better
- [ ] CPU has no "F" suffix (for example i5-8500, not i5-8400F), so it has integrated graphics for Jellyfin hardware transcoding
- [ ] RAM is 16 GB or more, or there are free slots to add it
- [ ] Has an NVMe slot or a 2.5" bay for the boot drive
- [ ] Has a free 3.5" bay for the photo drive
- [ ] Has room for a second drive for media later (a second bay, or plan an external drive)
- [ ] Power supply is big enough for two hard drives (ask for the wattage on the label)
- [ ] At least 4 USB ports, with a couple of them USB 2.0 if possible
- [ ] Has Ethernet (almost all do)
- [ ] The seller says the BIOS is not locked with an admin password
- [ ] Power adapter or cord is included
- [ ] No obvious damage, and it powers on

## Ask the seller

- Can you show it booting to the BIOS or desktop?
- Is the BIOS password-free?
- What is the exact model number, and can you send a photo of the label?
- Has it been used 24/7 or only lightly?

## Meeting tips

- Meet in a public place and test it before paying.
- Bring a monitor cable if you can, or ask to see it on a screen.
- Take a photo of the model label and ID for your records.
- Skip any listing that will not let you see it boot.

## Setting up alerts

Alerts are set up in your own accounts, so you do this yourself. Do it once per search.

### Facebook Marketplace

1. Open Marketplace in the app or at facebook.com/marketplace and type a search, such as `HP EliteDesk 800 G5 SFF`.
2. Set the filters: location radius (a distance you would drive), maximum price and condition.
3. On the results page, tap Save search (sometimes shown as a bell icon) and confirm you want notifications. On desktop, the filters are in the left sidebar.
4. In Facebook's Settings and Privacy, make sure Marketplace notifications are on.
5. Repeat for each model, plus a generic one such as `small form factor desktop i5`.

Facebook's saved-search alerts are not always immediate, so also open the app every day or two. Menu names change, so look for a bell or Save search near the top of the results.

### eBay

Search for the same models, then save the search from the results page and choose email or phone notifications.

### Tips

- Test the query first. If the results are full of things you do not want, change the search and filters before saving.
- Save misspellings as separate searches. Misspelled listings get less competition.
